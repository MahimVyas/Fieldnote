NO PAYWALL REQUIRED

Built to be yours.
Built with open tools.

Every layer of Fieldnote can run locally or on free tiers. Use hosted services when convenient, swap them out when you're ready.

01

Research agents

Four specialist agents run in parallel over independent sources, then an evidence reviewer deduplicates and ranks everything before the brief is written.

planner · reviewer · brief writer
02

Web & paper search

Wikipedia and an optional SearXNG instance cover the open web. Crossref, Semantic Scholar, and arXiv provide free scholarly metadata.

SearXNG · arXiv · Crossref
03

YouTube intelligence

Live YouTube search surfaces real watch links for every question, so video leads stay current instead of canned.

youtube search · watch links
04

Your documents

Local .md and .txt files are matched against your question on your own machine. Private material never leaves the deployment.

local files · offline matching
05

Interface

A dependency-free page served by the same Node process — dark mode, live agent progress, evidence map, and a saved-research library included.

Node.js · vanilla UI · Docker
THE PRINCIPLE
